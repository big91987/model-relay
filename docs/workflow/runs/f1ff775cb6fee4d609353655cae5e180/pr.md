# 打通首次配置、调用与同请求诊断的控制台体验

关联 Issue #16。本 PR 仅交付公共路线第1条纵向切片，不是完整团队网关、平台或新部署已完成；路线2–4按项目[唯一路线](../../../roadmap.md)以独立Issue接续。

## 用户得到什么

- 六页任务导航支持深链、刷新和过期重登录；桌面1280px及390px窄屏可用，任务键盘可达且焦点可见。
- 概览展示真实healthz版本、配置/启用状态、模型/密钥计数与下一步；未配置、已保存、当前配置曾成功调用明确区分。成功证据显示同一请求ID、时间、配置版本、别名和范围，配置改变/重启保守失效，未知不伪装成健康或零。
- 空业务配置通过UI接入唯一上游、建立别名、签发应用密钥、执行普通/SSE调用并核对同请求记录；依赖缺失可跳到对应页，创建/取消/编辑/启停有中文反馈与恢复操作。
- 密钥仅签发时展示，客户端示例使用占位符；拒绝、跳页、退出、会话过期清敏感内容，异步晚到不复活旧会话或污染新请求。
- 调用选择已启用模型，显示实际输入快照、可读文本/工具摘要、处理中/完成/失败/取消；提供有界原始诊断。SSE增量可见、取消生效、防重复发送，不自动重发或执行工具。
- 本次调用和概览成功证据均有明确同ID记录入口；可核对模型、密钥标识、状态、延迟及实际/未知用量，支持旧ID跨分页、刷新与重登录精查。普通记录导航仍是泛列表。

## 工程与安全边界

保持Go后端、SQLite、单管理员/单实例/唯一上游与原生前端。新增管理聚合/精确查询/会话期限信息及安全拒绝记账，管理权限不扩大，外部认证与生成错误协议保持兼容；拒绝不触达上游，存储失败仍fail-closed。无新表或数据库迁移，无多上游路由、治理配额或商业功能。

原位维护产品/路线/基础版本说明，补充真实Trellis规范与原固定验证入口的测试。没有产品内平台补丁、用户数据改写或秘密归档。运行、安装和备份继续使用[README](../../../../README.md)，正式测试部署遵循[既有部署说明](../../../local-deployment.md)；本轮未执行新部署或回滚。
