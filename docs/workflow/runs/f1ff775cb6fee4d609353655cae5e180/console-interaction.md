# 控制台原创交互设计（等价可评审原型）

本文件是逐页线框、状态/转移、焦点和场景契约，供管理员、研发与QA直接评审；不是可运行产品或浏览器验收。与 [架构](console-architecture.md)一起覆盖 [PRD](product-definition.md) 18条AC。只使用占位值，未嵌入秘密、演示记录或假统计。状态：Draft / 推荐执行。

## 1. 信息架构和视觉规则

控制台六页：概览、上游连接、模型别名、应用密钥、调用测试、调用记录。导航是真实链接 `/admin/#overview|upstream|models|keys|test|records`，仅页面白名单标识进入URL，不含密钥、消息、模型、请求ID或返回URL。空/未知hash替换为overview，API/静态资源路径不接收任意回跳。hashchange统一处理点击、历史前后与直接刷新；初次session成功后恢复当前页，过期重登录也恢复安全hash，不默认强制overview。记录目标ID由同会话内存传递，刷新后定位上下文丢失时明确提示并提供手动ID查询，不虚构恢复。

桌面1280px：整体最大宽1200px，左侧200px导航、右侧弹性内容（min-width:0），32px页面留白，内容与标题同轴。390px：16px外边距，品牌和退出换行，导航两列三行在内容上方，无抽屉/悬浮遮挡；卡片和表单单列，动作自动换行，输入宽100%，长ID/版本/别名按字换行；只有记录表本身容器可横滚。

视觉沿用原创深蓝品牌、白卡片、浅灰背景；主操作实色、次操作边框。状态以中文标签+文字/符号表达，不靠颜色；错误就地显示并包含下一步。按钮目标高度至少44px，焦点3px高对比轮廓；导航当前页 `aria-current=page`，页面只有一个h1。优先使用原生a/button/label/input/select/details/table，不用div模拟按钮。

通用布局：品牌/退出→跳至主要内容→导航→h1/任务说明→页级状态→内容→相关下一步。状态role=status，错误role=alert；载入区aria-busy；避免每个SSE字符强行朗读，只用状态区宣布“接收中/已结束”，输出区用户自主阅读。导航完成焦点到h1（tabindex=-1），初次登录焦点到密码，失败焦点到错误摘要或首个无效字段，列表行操作后留该行，关闭签发展示后回签发按钮。隐去面板不可残留Tab目标。

## 2. 登录及导航恢复

```text
Model Relay · 团队模型网关
管理员登录
管理唯一上游、公共模型和应用访问。应用密钥不能用于登录。
管理员密码 [ 密码输入 ] [显示密码]
[登录]
（过期时）管理会话已过期。敏感内容已清除，请重新登录继续“目标页面”。
```

保持既有显隐：切换不提交、不改密码；密码失焦/登录完成后隐藏；登录后清值。错误密码中文解释，限速提示稍后重试；不把内部英文code作为唯一文案。加载会话时不展示旧控制台内容。管理读取/写入401同步清秘密和输出、停止调用，显示登录；新登录不恢复测试消息或重新发送。

普通导航/返回/前进同样先清敏感内容与失效旧请求，再载入目标，载入失败仍显示正确标题/导航和“重试”，不空白。退出立即本地清除（即使网络退出失败），提示“本地内容已清除，退出服务端会话未确认，请重试退出”，不得假报服务端已登出。服务端退出成功后显示“已退出”。

## 3. 概览：理解真实状态

```text
概览
从接入上游到核对同一次请求；保存配置不代表供应商可用。
运行版本：{healthz原值或版本未知}                  [刷新状态]
上游：{未配置 / 已保存·启用 / 已保存·停用 / 未知}
模型别名：{total} 个 · {enabled} 启用
应用密钥：{total} 个 · {enabled} 启用

首次调用步骤
1 接入上游      {缺失/已保存}                 [配置上游]
2 建立模型别名  {无启用模型/已准备}           [管理模型]
3 签发应用密钥  {无启用密钥/已准备}           [管理密钥]
4 发起调用      {待核验/本次启动当前配置曾成功} [调用测试]
5 核对记录                                   [调用记录]
成功时额外显示：公开别名、时间、请求ID、上游配置revision、证据范围
                                              [查看该请求]
```

加载时计数为“加载中”，全量查询成功后真实0可显示；失败为“未知，读取失败”，不能以空表0替代。版本按现有5秒超时原值显示，独立失败不影响其他卡片。无图表/样本日志/健康徽章。仅已配置且启用、有启用模型/密钥才能建议调用；任何一步仍可进入管理页，不锁死顺序。

成功证据准确显示“本次服务启动、当前配置的模型X曾完成一次调用”，不是所有模型健康。保存/启停/签发改变配置后清成功证据，即使旧调用晚到也不变绿；保存仍显示“已保存，待调用核验”。服务重启无当前证明但保留历史记录入口。成功行来源和代次契约见架构§4.1。

## 4. 上游：保存与调用分离

```text
上游连接
一个供应商入口，服务端保存凭据。实际调用可能产生费用。
状态 {未配置 / 已保存·启用 / 已保存·停用}
上游Base URL [ https://provider.example/v1 ]
上游凭据     [ 密码输入 ]
{尚无凭据 / 已配置；同地址留空保留，改地址必须输入新凭据}
[ ] 启用上游
[保存上游] [撤销本页修改]
{保存成功：配置已保存；尚未证明供应商可用。} [前往模型别名]
```

初次空态不预填真实地址/凭据；占位地址仅placeholder。模型缺失时可前往模型，已有访问准备可前往测试。撤销恢复服务器公开地址/启停，无写请求、清凭据；必要非敏感未保存草稿留本页直到再次编辑或离开。保存失败保留地址/启用选择，清凭据并提示重新输入（保密优先），不改原对象。保存/撤销忙态不重复写。只显示credential_configured，无“找回凭据”。

错误地址定位地址字段；同地址空凭据允许保留，地址变化空凭据提示“地址已变化，请输入对应新凭据”；拒绝不触达供应商。保存后读取失败显示“保存已受理，但最新状态未读取，请刷新”，不把服务端已保存误当写失败自动再写。

## 5. 模型别名：创建、编辑、启停

```text
模型别名                              [创建模型别名]
对外别名映射到供应商模型。仅启用模型可被调用。
（依赖提醒）上游未配置/停用               [前往上游]
（已知空）还没有模型别名                 [创建第一个模型]
（有数据）别名 | 供应商模型 | 启用/停用 | [编辑映射] [停用/启用]

内联创建/编辑区
对外别名 [ ]（编辑时只读）  供应商模型 [ ]
[ ] 启用
[保存] [取消编辑]
```

空/加载/读取失败各有独立文案；列表查询上限沿用既有1000，本页提示“最多显示1000条”，概览计数不受此上限影响，不承诺无限模型选择。创建默认启用，编辑沿用原状态；已有上游尚未启用可保存别名，但提示尚不能调用，不强制生成伪对象。创建成功关闭编辑区、显示真实行；失败保留公开输入，alias冲突引导改名或编辑已有映射。取消不发写、不改变原行，草稿折叠在本页内存，再开可继续；离开可丢公开草稿，不为跨页持久化。编辑模型实际名称及启停都走既有PATCH，UI不能创建另一个对象来假装编辑。

行启停显示处理中，该行禁止重复点击；失败保留服务器原状态、允许重试。选中停用模型后进入测试时应重新获取列表并清无效选择；不默默改选另一个模型发送。

## 6. 应用密钥与客户端接入

```text
应用密钥                            [签发应用密钥]
完整值仅签发时出现；遗失后重新签发并停用旧值。
（空态）尚无应用访问凭据              [签发第一个密钥]
密钥名称 [ ] [签发] [取消]
（签发响应当次）新密钥 [一次完整值，默认密码形态]
[显式复制密钥] [关闭展示]
请安全保管。跳页/刷新不可找回；剪贴板由你负责。
列表：名称 | 安全提示/标识 | 启用/停用 | 创建时间 | [停用/启用]

客户端接入
网关Base URL：{location.origin}/v1
客户端示例（仅占位密钥）               [复制示例]
```

完整值不使用URL/localStorage/sessionStorage/IndexedDB；不提供默认“带密钥跳到测试”动作，本轮选择手动粘贴到测试密码输入。关闭后清DOM与引用，只保留名称/ID/hint，复制不会自动读取/清空系统剪贴板。签发前同步忙锁；发请求前清上次一次值；未知提交结果不能自动重签，提示“签发结果未确认，刷新列表后决定是否重新签发，并停用遗失值”。列表无法找回完整值。

复制操作明确用户触发；失败“无法自动复制，请手动选择复制”，不触发调用或新增密钥；可访问只读输入允许选择。成功异步剪贴板回调需身份检查，不能在新页显示旧通知。截屏/报告只能在关闭展示并清测试字段之后；受控测试密钥也不入截图。

调用示例为用户选中的公开别名；无模型用 `YOUR_MODEL_ALIAS` 并附解释，不选择供应商模型名。安全引用/转义字段值，网关地址来自页面origin而非供应商配置。示例：

```sh
curl 'GATEWAY_BASE_URL/chat/completions' \
  -H 'Authorization: Bearer YOUR_APP_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"model":"YOUR_MODEL_ALIAS","messages":[{"role":"user","content":"你好"}],"stream":false}'
```

页面把GATEWAY_BASE_URL替换为真实网关的`origin/v1`，别名已选择时做可靠shell/JSON转义或仅保持占位符并另列已选别名，不直接拼接未转义输入；始终保持YOUR_APP_KEY占位。文案说明URL已经含/v1，不能拼成/v1/v1。

## 7. 调用测试：输入、输出与取消

```text
调用测试
向真实网关发送一次请求；可能产生费用，不自动重试。
（依赖）{上游未配置/停用/无启用模型/无启用密钥} [对应页面链接]
模型别名 [启用模型选择器]
应用密钥 [密码输入，手动粘贴]
消息     [多行输入]
[ ] SSE流式
[发送一次请求] [取消请求]
状态：{待发送/等待首包/接收中/完成/失败·不完整/已取消}
可读输出：{文本，或工具结果摘要，或尚无输出}
网关请求ID：{收到的X-Request-ID，或未取得}
[查看同一请求记录]
<details>原始响应诊断（可能含敏感内容，离开即清除）</details>
```

存在启用模型但列表读取失败时不可用未知替代空；用户重试读取。无可用模型禁用发送并给依赖链接；有模型不代表上游成功。密钥输入非空不代表有效；不从摘要恢复。开始提交保持输入可见以理解当前调用，禁止改写进行中的参数；选中模型/SSE为非敏感修正项可在失败后保留。失败清应用密钥及原输入消息，明确提示重新输入后显式发送；不丢公开选择、不自动请求。错误结果只展示网关安全类别。

| 状态 | 可用动作与呈现 | 下一状态 |
|---|---|---|
| 待发送 | 选择/输入/发送；取消禁用，显示“尚未发起” | 同步忙锁→等待首包 |
| 等待首包 | 发送禁用，取消可用，输出空；取得头后立即保留网关ID | 普通读取/SSE接收；或失败/取消 |
| 接收中 | 逐段文本可见，发送禁用；不把局部内容称为完整；原始诊断可展开 | 合法终止→完成；错误/缺DONE/断流→不完整 |
| 完成 | 显示文本或“收到N个工具调用结果；可查看诊断”，不执行工具；可查记录/显式新调用 | 新请求获得全新身份并清旧输出 |
| 失败/不完整 | 显示中文类别与修正入口；部分文本标为不完整；原始仅当前页，可查已取得ID | 用户修正/重新输入后显式发送 |
| 已取消 | 清密钥/消息/输出/原始诊断；保留非敏感ID（若已收到）；提示费用与终态可能待落盘 | 查记录/显式新请求；旧回调不得改状态 |

跳页、退出、过期均同步取消并清敏感内容，不显示旧页输出。测试取消没有拿到ID时只能说明无法定位，不找“最新一条”。按架构§6检测长流/驻留页面会话失效；网络会话确认失败用独立提示，不与应用401混淆。

## 8. 调用记录：精确定位与历史分页

```text
调用记录
仅安全元数据；缺失用量为未知，不能当零。
定位请求ID [内存交接或手动输入] [查找同请求] [清除定位]
定位结果：{加载 / 精确ID记录 / started待终态 / 暂未找到 / 读取失败}
[刷新该请求]
目标卡片：ID、时间、公开别名/真实模型、密钥ID、状态/错误类别、耗时ms、输入/输出/总token
最近记录 [刷新列表]
ID/时间 | 模型/密钥 | 状态 | ms | token          [下一页]
```

定位卡独立于列表；找到后用标题“该请求”和文本边框突出，不仅靠颜色，焦点到卡片标题。模型/密钥缺失显示未知；用key_id匹配当前元数据可显示名称，但身份以key_id为准，名字不是归属依据。未知密钥拒绝显示“未识别应用密钥”，不能显示不存在的名称或hint。密钥和真实供应商token绝不出现在记录。

started显示“网关已受理，结果尚未落盘”；终态显示success/rejected/upstream_rejected/upstream_failed/timeout/stream_interrupted/canceled/process_interrupted对应中文。精确404显示“暂未找到该ID记录：可能尚未落盘或未能记录”，允许手动刷新；503说明存储/读取故障并给运行说明入口。没有记录不意味着请求未计费。取消本地状态与数据库终态分开标记，不能本地造canceled行。

分页按钮按既有next_cursor控制，刷新列表重置cursor；更旧记录仍通过精确ID可查，与并发新增无关。未知duration/usage/status为“未知”，null与真实0严格区分。列表加载失败保留已成功载入行但注明不是最新，定位失败不得拿列表另一行顶替。手动ID输入不进入浏览器URL/存储，不产生生成POST。

## 9. 中文错误与恢复动作

code保留在可展开的安全诊断元数据中，默认中文说明；不展示上游错误message原文。

| 来源/code | 默认反馈及恢复 |
|---|---|
| 管理unauthorized | 会话失效，清内容，重新登录当前安全页面；登录错误密码另提示密码错误 |
| 生成unauthorized | 应用密钥缺失、无效或已停用；重新输入，管理员前往密钥确认；不登出管理员 |
| invalid_destination / new_credential_required | 地址不符合规则/地址变化须新凭据；聚焦对应字段 |
| invalid_model / alias_conflict / invalid_name | 修正模型字段/别名已有/密钥名称；保留公开草稿 |
| upstream_unavailable / model_unavailable | 上游未配置或停用/模型不存在或停用；前往上游/模型，恢复后显式重发 |
| upstream_rejected / upstream_rate_limited | 供应商拒绝/暂时限流；核对供应商授权额度或稍后手动再试；不自动重放 |
| upstream_connection_failed / upstream_redirect | 无法连接/上游重定向不受支持；管理员修正地址和网络；拒绝跟随重定向 |
| upstream_timeout / stream_interrupted / upstream_protocol_error / upstream_http_error | 超时/流不完整/协议不合法/上游服务失败；查看本次记录与安全诊断；已输出不自动重试 |
| storage_unavailable / process_interrupted | 存储故障或服务重启中断；按README正式停服排查/恢复；不反复生成 |
| invalid_csrf / untrusted_origin | 管理请求安全校验失败；不自动重写，重新登录本服务正式入口 |
| invalid_request / request_too_large / unsupported_field | 输入或协议字段不支持/消息过大；修正后手动发送，不吞掉协议错误 |
| login_rate_limited / session_limit / not_found / invalid_cursor | 稍后登录/会话数达到限制/目标不存在/分页信息无效；重登录或刷新对应列表 |
| fetch失败/未知code/复制失败 | 区分未取得网关ID、网络连接失败与自动复制失败；提供检查服务/重新读取/手动复制，不臆测成功或归属 |

## 10. 评审场景（未来验证，不是通过记录）

1. 空业务配置真实服务：登录→概览真实0→UI保存唯一上游→UI创建别名→UI签发受控密钥→手动用于普通测试→得到可读文本和ID→同记录逐字段核对→SSE在结束前有增量→核对同SSE请求。步骤之间不API/SQL预填。
2. 修改上游地址/凭据、模型映射、密钥启停，概览撤回当前成功标记；挂起旧调用跨配置变化，旧成功不得恢复；服务重启只显示历史证据，记录完整保留。
3. 任意页hash直达/刷新/前后，未知hash恢复；在管理读取/写入及测试长流中会话失效，中文重登录回目标、秘密清除、不重发；生成401不退出管理员。
