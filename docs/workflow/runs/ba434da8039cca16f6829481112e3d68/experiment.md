## 固定条件和采样

- 实际Go网关、隔离临时目录和临时端口、两个明确标识的受控Go HTTP上游；不接用户配置或供应商。模型、固定合成请求、候选priority=0/weight=1、输出字节数/合法usage/价格/可信token上界完全一致；不存请求/响应正文。
- A/B 起始均无样本。普通与SSE分别运行，独立池、独立安装或显式进程重启；实验不以残留样本预热。两轮重复，执行次序第1轮 weighted→low_latency，第2轮 low_latency→weighted。
- 稳定阶段每策略每模式每轮40个预定学习请求+120个计分请求。学习请求全部保留，但不计稳态收益；启动行为另评。无sleep挑样，不丢慢请求/失败/重试；不按通过与否动态增加请求。
- 上游快/慢首body定时为20ms/100ms，响应头可立即发送，首body后统一20ms普通尾部/SSE150ms尾部；两个上游同模式同尾部、同输出。独立客户端同时记录单调端到端完整耗时，Go上游记录派发/首body/结束相对时间，服务端诊断记录body_ttfb。
- 模式分开顺序调用（并发1），同一策略稳定阶段后不重启直接互换两上游20/100ms，固定120请求；最后80计分，前40为预定适应段且仍报告。
- 总量：2轮×2模式×2策略×(40+120+120)=2240请求，不含下列故障/边界。所有上游都是明确测试夹具，未计真实费用。

## 预先锁定阈值与依据

| 场景 | 样本/控制 | 验收阈值 |
|---|---|---|
| 全无样本 | 每稳定阶段最初40 | 不能把unknown当0；双方获得有效样本；回退/探索理由可追踪 |
| 稳态 | 每120计分请求独立判断，不能只汇总掩盖失败 | weighted快候选占45%–55%；low_latency快候选>=80%；body_ttfb均值比对应weighted降低>=35%；两策略成功率100%，每请求仅1 attempt |
| 速度互换 | 每120中最后80独立判断 | low_latency新快候选>=75%；最迟40次选择内出现以新评分选中新快者；weighted维持45%–55%；成功率100%，每请求1 attempt |
| 输出尾部对照 | 每模式每策略再20请求，首body均20ms，一方尾部20ms另一方200ms，隔离冷启 | 诊断首字节不包含尾部时长；不声称端到端/输出长度收益；无失败；两方都获探索，不要求无噪声时精确50% |
| 无样本/新候选/过期 | 注入时钟单测，n=1/2/3/100；HTTP另每模式12请求 | TTL边界60秒有效、超过失效；少于3不评分；稳定集合每候选<=5n次得探索；新候选/重启显示unknown而不是旧EWMA |
| 失败/冷却/恢复 | 每模式每策略30请求；第1–6次对慢端可编程503，冷却由注入时钟推进 | 冷却内0次命中；冷却结束<=10次同组选择获真实恢复尝试；失败不更新成功评分；成功/失败数与每请求attempt全保留，不要求故障段100%成功 |
| 并发/迟到 | 每模式16并发，barrier安排先发后到、成功/超时/取消与中途配置变化 | 旧配置/较旧序列结果不覆盖当前池；race无报告；开始/结束/归因可重建，无重复结算，无未释放并发占位 |
| 头先到/心跳/断流 | 每模式定向HTTP至少各1例早头、晚body；SSE另各1例早心跳后成功/失败、输出后断流/取消 | body_ttfb非headers；失败无有效样本；首输出或取消后上游尝试数不增加 |

依据：等权二候选首字节理论均值60ms；20%轮换探索使慢候选约10%，理想均值28ms（约53%改善）；80%占比和35%改善保留冷启动、调度和采样抖动余量，不是事后挑阈值。互换适应40次相当四次最慢候选探索机会；alpha=.25在明显80ms差距下应能重新排序。p95可能仍由探索慢端决定，不要求降低或隐去代价。任一轮失败如实Fail，不反复跑到绿色；环境抖动归因须保留原始样本。

## 统计和原始证据格式

逐请求JSONL：实验版本/运行ID/轮次/场景/模式/策略/固定序号/Request ID、阶段、时间窗口、首字节/完整耗时、选中上游、成功终态、attempt数及各attempt上游/状态/延迟、选择原因/观测数/EWMA/年龄/代次。记录客户端和网关可比指标，没值用null；不放正文、凭据、session、带认证URL、本地绝对路径。

逐窗口汇总：全部请求数、成功数/率、总attempt、上游分布、TTFB与完整耗时均值/p50/p95（nearest-rank，排序后ceil(p*n)）、学习/适应与计分段分别列出、缺失数、开始/结束UTC。失败请求不从成功率和attempt分母消失；无首字节的样本不当0，另列缺失及原因。报告受控实验收益、探索慢尾和学习成本，附原始数据可复算命令和静态SVG对照，禁止宣称供应商性能。
