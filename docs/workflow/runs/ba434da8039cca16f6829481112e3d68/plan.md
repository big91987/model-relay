## 1. 当前实现与新增差异

实际阅读：根 AGENTS.md、docs/roadmap.md、docs/releases/v0.1.0.md、configuration.go、routing.go、routed_proxy.go、proxy.go、store.go、upgrade.go、console_storage.go、console.go、web/workspace.js、Makefile 和 tests/verify/main.go（源码均在 internal/relay 下，除非另注）。

现有：同模型候选，先鉴权和准入，再按启用/凭据/冷却/已尝试过滤，最高 priority 组使用平滑加权轮询；最多三次上游尝试，首输出后或取消后不重试；按执行修订隔离健康；SQLite 主格式 1/2/3；管理台已有模型候选编辑、请求详情、费用与权限。健康未知的候选允许首次正常流量尝试，不把未知等同已证健康。

新增：每个公共模型可选 `weighted`（默认）或 `low_latency`；只更换最高优先级合格组内部排序/探索，不改变候选授权、准入、冷却、重试、价格、收费上界或预算。无成本/能力替换，无学习分类器、分布式调度、隐藏探测和外部付费调用。真实供应商 Not Run。

## 2. 延迟指标与样本有效性

推荐采用 **响应体首字节延迟 body_ttfb_ms**：从开始真实上游 HTTP 尝试（client.Do 前，包含连接/排队）到 response.Body 首次成功读到非零字节，单调时钟计时。不使用仅响应头到达，也不使用完整生成 duration。普通和 SSE 使用相同传输口径，但维护分离观测池，不能互相比较。

- 普通响应：首 body 字节仅暂存，只有完整响应合法并成功完成后才成为成功样本。
- SSE：首 body 字节可能是心跳、注释或 role-only 事件，因此明确称传输首字节，不宣称首 token。也须合法终止且没有取消/超时/断流/写出失败才采纳；先发心跳后失败绝不是快速成功。测试单列早心跳和长尾。
- 保留 existing duration_ms 完整耗时作诊断，不参与排序。首字节无法测得、未完成、失败和历史数据均为 null/unknown，不写零。不采集正文或 token 内容。
- 成功持久化与采纳之间再次检查父 context、当前模型/候选/上游执行身份、策略代次；旧快照/禁用/删除重建/改远端/改凭据/改策略后的迟到结果均不能更新当前观测。
- 并发结果按 dispatch sequence 处理：不允许较早派发的迟到成功覆盖较新结果；保持既有健康更新语义。有效成功后才更新 EWMA，存储失败不采纳。
- 正常 weighted 流量也可采集同口径观测；切换策略开启新代次并清空该模型池，避免切换前在途结果污染，历史诊断不删除。

## 3. 排序、探索、过期与恢复（冻结参数）

单进程、模型+普通/SSE 模式+上游 ID/执行修订+候选执行修订+策略代次作为池键；最多每候选每模式一个聚合状态，配置删除及时清理，不存请求内容。

1. 完全沿用既有过滤和最高 priority。重新检查当前授权/启用及执行修订；快照已过时则拒绝该旧候选，不使用新凭据替换快照后继续发起。
2. `weighted` 保持原平滑权重逻辑及默认行为。`low_latency` 不解释为权重自动调整，权重仅在无可评分候选时作回退。
3. 有效成功样本 EWMA：首个值直接赋值，后续 `0.25*new + 0.75*old`；有效成功数至少 3 才可评分；成功计数饱和至安全上限。最新成功超过 60 秒则池重置为 expired，重新收集 3 次，不沿用旧值。
4. 每五个该组实际选择中的第 5 个为探索：选择最长未获得探索机会的合格候选，初始按 upstream ID 排序；派发时推进探索轮换，不能等待成功才推进。其余四个选择最小有效 EWMA，完全相等按 ID；全无可评分样本时回退既有平滑权重。
5. 探索机会轮换独立于 EWMA 成功，不因失败/并发在途永久卡住。对稳定的 n 个持续合格候选，最多 `5*n` 次同模型同模式组内选择获得一次探索机会（n<=100）；两候选最多 10 次。该界限是请求次数而非墙钟 SLA，无流量时不主动探测。
6. 窗口与轮换在 server.mu 内原子更新，网络调用在锁外。候选集合变化重置组轮换和权重状态；频繁配置变化不承诺原稳定集合界限，须在诊断保留代次。
7. 临时失败沿用冷却，冷却内排除。冷却结束先视为未评分候选，清除失败前的低延迟评分，最迟上述探索界限内用真实流量重试。永久失败的已有规则不变，绝不为了探索绕过冷却/资格。
8. 服务重启保留策略和请求诊断，不保留内存 EWMA/探索计数；页面显示「无本进程样本」，依默认回退重新学习。没有将历史平均伪装为当前观测。

依据：20% 总探索预算在双候选时约 10% 流量持续给慢候选，保留恢复机会；alpha=.25 使新观测约八次后占 90%；60秒约束近期性，不构成对真实供应商性能的保证。实验阈值与代价见 experiment.md。

## 4. 配置、兼容与持久化

推荐最小增量、带独立版本的 routing 扩展表，而不将所有现存 `Schema==3` 运营分支改成主格式4：

- `routing_extension_meta` 单行版本1；`model_route_policies` 按 alias 外键保存枚举策略；缺行含义 weighted。
- 独立 request/round/candidate 选择证据表和 attempt 延迟证据表，引用现有主键，不改变旧 request_route_decisions 的列数/位置。旧历史没有扩展证据时返回 unknown，不补造。
- init、显式 upgrade、正常 open 共用一个事务式幂等扩展迁移；先完成原安装身份/密钥/格式校验，再执行扩展检查和迁移，失败拒绝启动且不留部分表/默认值。拒绝未知扩展版本，不能把损坏格式当空表自动修好。主格式1仍须先原显式升级；2/3均覆盖。
- 策略保存与模型配置修订、CAS expected_revision、config_revision 在同一事务。POST 省略策略=weighted；PATCH 省略=保留现值；非法枚举400；旧客户端不静默重置新策略。
- 策略或相关执行配置变动递增模型路由代次，使在途结果不再适用于当前池；纯展示字段不必无关失效。诊断记录实际快照的修订。
- 备份/恢复及 validateMaterial/validateStorage 扩展验证，禁止删库升级或修改业务记录求绿。旧二进制不会理解新策略；回退须先切回 weighted、导出/备份并按已测兼容路径操作，不能宣称任意历史版本可安全使用新策略。
- 每条选择证据持久化实际策略、模式、算法版本、选中原因(explore/lowest_latency/weighted_fallback)、样本状态、有效数、EWMA或null、最新观测时间/年龄、TTL、探索序号/界限与配置代次。必要字段每候选每轮限量存储，不记录提示词、正文、URL凭据或任何 token。

## 5. UI 与连续用户旅程

在现有模型/路由编辑器增加有标签的策略 select：「权重（默认）」与「低延迟优先」。旁文说明普通/SSE传输首字节、20%探索、60秒过期、重启重新学习、探索仍可能正常收费。保持候选、priority 和 weight 字段；选择低延迟时说明 weight 只作未知回退，不禁用原配置。

保存成功须读取实际保存结果；409冲突和503失败保留编辑数据，不能假成功。重新进入和重启后策略可见。请求详情以同 Request ID 展示策略、选中服务、原因、观测未知/过期/数值与完整耗时区别；沿现有租户/Key/诊断授权过滤，费用与日志保持同 ID，不展示敏感字段。390px字段纵排、说明换行、必要表格容器内滚动，不让全页横向溢出。

真实浏览器分别以桌面和390px在实际 Go 服务上完成：创建两个受控同模型上游→候选→选择低延迟并保存→离开重入→发普通/SSE调用→同 ID 请求诊断/日志/费用→切回权重→重启读回。准备可使用显式夹具建租户/身份/价格/可信上界，但上游/候选/策略配置、调用和诊断步骤必须操作页面，不能用 API/SQL 代替。重启由测试进程完成，浏览器恢复后验证。

## 7. 实施顺序和固定门禁

设计检查正式接续后依次：扩展迁移/API与配置回归→观测/选择/诊断与确定性负例→管理UI与双屏实旅程→预注册对照及可读汇总→定向Go/race与前端测试→归档源码摘要并handoff tests。必要测试进入现有 make verify，不另建只跑新功能的替代门禁。

不在研发节点提前完整自跑 make verify。固定节点仍25分钟内层/30分钟外层；不改预算、不预装隔离candidate、不删阶段、不弱断言。新增预计串行受控实验<5分钟、两屏旅程<2分钟，单测/race新增<1分钟；这些是设计估算不是实测。实现后用定向阶段实测加既有完整阶段回执评估余量，若预计越限正式阻塞并提出分阶段建议，不裁用例。失败保存EOF/原退出码，实质修复后才再交。

仅使用官方 Go net/http Response/Client 文档、Go time Monotonic Clocks 文档、SQLite Transaction 文档解释响应体读取、单调计时和事务边界；不是既有 relay 实现来源，也不是供应商协议兼容证明。官方页面地址分别为 `https://pkg.go.dev/net/http#Response`、`https://pkg.go.dev/time#hdr-Monotonic_Clocks`、`https://www.sqlite.org/lang_transaction.html`（2026-10-25查阅）。不改变项目锁定Go工具链或模块。
