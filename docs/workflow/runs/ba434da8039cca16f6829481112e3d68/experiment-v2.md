状态：设计检查修订，尚未批准、尚未观测。v1 experiment.md原字节保留；变更理由是SSE评分目标失配和全门禁预算不足，不是根据结果调标准。与plan-v2.md一起检查；新增指标替换SSE传输口径，但保留快端比例/改善百分比阈值。

## 1. 固定条件与核心2240请求（不减样本）

真实Go服务与受控Go HTTP/SSE上游、临时端口/数据、同公共模型、同合成请求/输出字节/usage/价格/可信上界；等priority=0、weight=1。无真实供应商、无生产配置。普通与SSE分池。

两轮，每轮每模式每策略一条独立冷启cell，共8cells；轮1 weighted→low_latency，轮2 low_latency→weighted；每cell内并发1，所有cells串行，期间不跑浏览器/编译/别的实验，避免共享机器并行干扰。

每cell固定40学习+120稳态计分+120速度互换，互换前不重启，前40适应/后80计分。共2轮×2模式×2策略×280=2240。全部请求/失败/重试保留，不动态补样；未达到任何阈值即Fail，不能只看总平均掩盖某轮失败。

快/慢评分测量点20/100ms：普通首次body字节；SSE第一完整非空content delta（基础cell无早心跳）。响应头立即flush。首输出后统一5ms再完成相同长度输出（普通JSON合法闭合、SSE合法终止），双方同尾。只有这一重复尾部由v1普通20/SSE150ms改为5ms，**不减首输出差80ms、不改输出字节数/合法性、不删除长尾覆盖**；专门80请求在第3节保留长尾。

| 核心场景 | 固定验收（逐cell判断） |
|---|---|
| 冷启40 | unknown非0；双方获有效成功样本；不足3不评分、回退/探索可追踪 |
| 稳态120 | weighted快端45%–55%；low_latency快端>=80%；对应模式评分延迟均值比weighted降低>=35%；两策略成功率100%，每请求1attempt |
| 互换120的后80 | low_latency新快端>=75%；最迟40次选择内出现按新有效评分选择新快端；weighted45%–55%；成功率100%，每请求1attempt |

普通与SSE分别比较，不能用普通收益抵消SSE失败。SSE指标是first_output_delta，绝不以body_ttfb达标替代。20%轮换探索理想双候选约10%慢端，理想首输出均值28ms，对照60ms，理论约53%改善；80%/35%阈值维持原余量，互换75%/40次也不降低。

## 2. 成功早心跳陷阱（新增160请求）

单独SSE安装/池，一轮weighted→low_latency，每策略40学习+40计分，160请求，串行并发1。A：1ms注释/心跳、3ms role-only、5ms空delta/空content等合法非输出事件、100ms首次非空content；B：20ms首次非空content，无提前心跳；双方最后有效输出后5ms结束，最终成功、输出及usage一致。发送时钟按attempt处理开始的绝对偏移，而不是把分段等待累加；事件均完整flush。

- weighted在40计分中B占45%–55%；low_latency中B>=80%，first_output_delta均值相较weighted降低>=35%，成功率100%、1attempt。这个补充场景40计分不替换核心120，效果阈值不降低。
- 每请求保留上游首body、首有效增量和完成时刻对照，确认A传输更早但有效输出更晚；A不能靠1ms心跳胜出。
- 独立功能反例：role-only/空delta/空content/usage-only/finish-only/DONE不触发测量；非空content/refusal/tool function.name或arguments触发；工具id/type/index-only不触发；非法空data仍走原错误，不放宽协议。
- 合法完成但始终无有效输出：请求可成功，metric null，sample_state=no_output_delta，不能被当成0ms快成功。首内容前取消、心跳后断流/超时、终端[DONE]写失败均不得采纳成功评分。

## 3. 输出长尾独立反例（保留80请求）

每模式每策略20请求，独立冷启，共2×2×20=80。两候选评分测量点均20ms，一方尾部20ms、另一方200ms，内容/输出长度和usage相同。核心重复尾部缩短不影响此处的长尾覆盖。

断言：排序指标在各自测量点记录，而不是约40/220ms完整时长；两端都有正常探索机会，选择证据与当时EWMA可重算；不要求微小噪声时恰好50%；报告完整duration分布，不把不同输出尾部当首输出收益。SSE加早心跳/role事件时不得提前测量；普通只对其body指标验收，不谎称用户首内容。

## 4. 时钟/失败/并发负例（必进原Go race/HTTP阶段）

使用可注入时钟/barrier，不sleep61秒、无真实供应商。既有正常冷却回归/实际等待原样保留，不能用新注入测试替换旧覆盖。

| 场景 | 预注册规模/控制 | 必须结果 |
|---|---|---|
| TTL起点 | 两模式各测measured=0，finish=59/60/61秒；各独立初态 | 完成59/60秒可采纳且年龄59/60；61秒拒绝expired；年龄从measured不是finish/accept起算 |
| 采纳后过期 | 测量0，完成59，选择在59/60/60+epsilon；每模式各1组 | 只再有效1秒；60秒有效，超过即过期；不能从完成续60秒 |
| 每样本过期 | 旧样本0/1/2，新样本59，选择61/62/62+epsilon；两模式 | 各样本独立清理，count/EWMA重算，不把整个聚合用新时间续期；不足3unknown |
| 无样本/新候选 | n=1/2/3/100确定性选择；两模式另各12真实HTTP | 稳定集合每候选<=5n次获探索，公平推进以dispatch非success；重启/新增unknown |
| 失败/冷却恢复 | 两模式×两策略×30请求；1–6次慢端访问503；钟推进冷却 | 冷却内0次派发；结束<=10同组选择获恢复机会；失败不刷新成功时间或EWMA；所有attempt/失败都报告 |
| 并发/迟到 | 每模式16并发，barrier指定顺序 | 较旧序列/较早测量不覆盖新池；中途禁用/换远端/凭据/策略/删除重建的结果拒绝；占位/记账释放一致，race无报告 |
| 流终态 | 输出前取消、输出后取消、断流、空流、心跳后失败、终端写失败各独立HTTP例 | 失败/取消无成功样本，已输出/取消后不增加派发，成功提交与采纳顺序可验证 |
| 权限与准入 | 两策略参数化，跨租户/Key、额度、非零RPM/TPM、并发、金额预算分别命中 | 拒绝不触达上游；额度种类不互相替代；探索不绕过原条件；诊断不越权 |

长SSE通过HTTP barrier使真正的第一增量已传输后再推进时钟；不是纯手造最终样本代替整个采纳路径。生产仍使用真实单调时钟，不为实验加公开时间控制入口。历史进程未知及存储失败保留unknown，测试不能SQL改业务记录求绿。

## 5. 精确执行归属：每个固定门禁只跑一次

## 6. 可复算逐场景/模式/轮次预算

以下不是实际测量或deadline。用秒，首输出快=.020、慢=.100，统一尾=.005；一个cell=一轮×一模式×一策略。两模式、两轮相同条件，因此每策略有4cells。

| 每cell场景 | 数量 | weighted定时等待 | low_latency规划定时等待 |
|---|---:|---:|---:|
| 学习 | 40 | 40×(.060+.005)=2.600 | 同样按等分规划2.600 |
| 稳态 | 120 | 120×(.060+.005)=7.800 | 120×(.028+.005)=3.960 |
| 互换 | 120 | 120×(.060+.005)=7.800 | 前40全部慢4.200+后80按90%快2.640=6.840 |
| 每cell小计 | 280 | 18.200 | 13.400 |
| 每策略4cells合计 | 1120 | 72.800 | 53.600 |

核心2240定时等待规划126.400秒。为不只拿理想90%分布当上界，另按最低合格分布算：

- weighted：学习40+适应40全慢，稳态120+互换计分80最多55%慢，4×[80×.100+200×(.55×.100+.45×.020)+280×.005]=88.800秒。
- low_latency：学习40+适应40全慢，稳态最多20%慢、互换计分最多25%慢，4×[40×.100+120×(.8×.020+.2×.100)+40×.100+80×(.75×.020+.25×.100)+280×.005]=67.680秒。
- 合格分布定时等待156.480秒；另预留每请求15ms Go/SQLite/日志/调度开销，共33.600秒，合190.080秒，预算向上取191秒。15ms是待研发验证的工程假设，不伪称已有冷candidate基准。
- 若完全选慢而不达标，定时等待2240×.105=235.200秒，含同一开销268.800秒；如实Fail且保留，不能为赶预算丢失败样本。OS/存储无限延迟无数学上界，仍受原门禁控制。

## 8. 原始证据与统计
