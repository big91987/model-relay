## 2. 目标、运营方式与范围

本产品是团队持续运营的模型服务管理控制台：让平台管理员准备供应商与已有推理服务，让内部租户安全使用模型并承担可核对的预算与费用，让开发者定位调用，让财务观察者读取本租户分账材料。

需求证据为用户#25委托及冻结 PRD；现状替代方案是既有基础代理、配置表单及首次调用体验，不能满足租户身份、共享资源治理和账单闭环。不交付的影响是应用边界和费用责任无法可靠核对。未提供用户采用率、请求规模或生产SLO证据，不补造这些指标。

成功口径：A工作台完整业务闭环、全部P0规则与失败结果可观察；普通/SSE真实Go服务；1280/1440/390实际UI及键盘旅程；固定 `make verify` 与独立QA逐项证据；同产品PR与最终部署版本一致。材料合格、设计就绪、产品通过、正式发布分别判断。

所有US01–US08与AC01–AC18是本期P0，H01–H08是交付可信度要求。可按旅程分批研发，但不可裁剪成几个表单或旧M1切片。`docs/roadmap.md` 和 `docs/releases/v0.1.0.md` 的Go、安全、协议与运营回归保留；旧单管理员、仅M1和不做多租户分账的阶段限制由本次最新委托替代。

非目标：GPU部署/调度、训练、多区域高可用、公开售卖、充值/支付/退款；其他模型能力必须标清不可调用边界。真实供应商报价、外部身份与支付联调缺条件记Not Run；受控HTTP/SSE可证明项目语义，不能证明供应商事实。未来出现外部售卖、GPU运维、额外协议或规模SLO需求时重新定义边界，不预建这些能力。

## 3. 业务责任、首次可用与生命周期

平台管理员负责模型服务、安全、价格、全局异常与账单关闭/更正；租户管理员负责本租户成员、应用Key、预算和密钥泄露处置；开发者只在分配的应用诊断范围内排障；财务观察者只读本租户费用；服务提供者承担已有端点、能力、凭据和真实供应商用量。成员身份与应用Key相互独立。

当前采用平台自管及租户管理，不依赖企业共享身份平台或支付平台才能首次使用。维护者负责正式安装、备份、恢复和容量边界，平台管理员负责供应商支持，租户管理员负责应用支持；不承诺未定义的全天候SLA。

| 核心对象/来源 | 首次可用入口与责任 | 可用核验 | 变更、异常、退出 |
|---|---|---|---|
| 管理身份/新安装或旧管理员 | 维护者经受支持Go初始化/启动入口取得首次管理身份；平台管理员登录；设计闭合迁移后身份归属 | 空数据目录登录可管理，调用Key不能取得管理权限 | 初始化不覆盖旧数据；降权/退出立即收回身份，敏感界面及迟到响应清除 |
| 模型服务/供应商API或已有端点 | 平台管理员通过正式服务UI接入，提供者给端点/凭据/能力 | 保存与连接、生成核验分离，失败可修正重试 | 改配置旧核验失效；停用拒绝新请求；保留历史，不部署算力 |
| 公共模型/远端能力 | 平台管理员通过模型UI发布公共名、映射、能力与价格，再显式授权租户 | 未授权调用零dispatch；授权后真实普通/SSE调用 | 新模型/组合不扩大原授权；停用立即作用新请求；输出后不重放 |
| 租户/内部团队 | 平台管理员通过租户UI创建，授模型与预算，邀请负责人 | 负责人接受并认证后成为有效管理员，跨租户访问拒绝 | 暂停所有Key新调用；恢复按当前规则且不清用量；历史账单保留 |
| 成员/邀请 | 租户管理员邀请，受邀者经正式接受及认证入口加入 | 邀请带角色/到期，接受前无权；服务端身份确定角色 | 角色变更/移除收回权限与Key诊断分配；最后管理员先交接，不盲目撤应用Key |
| 应用Key/租户应用 | 租户管理员通过Key UI签发、限模型/期限/额度并分配诊断成员 | 一次性秘密、授权交集、普通/SSE结果及同ID详情 | 启停/撤销/轮换；最长24h且不叠加；新旧共享应用池和历史；未知提交先读回 |
| 配额预算/平台及租户约束 | 平台管理员设平台限制；租户管理员在限制内通过配额UI管理 | 次数/RPM/TPM/并发/软硬费用独立且租户和Key同时生效 | 零拒绝与无限区分；改限额/跨窗/重启不清旧事实；未知保留保守预留 |
| 价格/平台配置USD测试价 | 平台管理员通过定价UI发布成本与租户费输入/输出费率 | 每请求受理快照，整数微美元与舍入可核对 | 新版生效不回算历史；测试价不称供应商报价 |
| 用量与账单/实际dispatch | 系统记录请求全部尝试；平台管理员经正式核对/账单入口处理未知项、结账与更正 | 明细/汇总/导出一致；已结束无待确认才可结账 | 未知非零；追加可核验差额且幂等；更正保留原金额/原因/操作者/调整周期，不改请求 |

邀请邮件或外部身份服务不是既定联调条件；设计应给出不依赖缺失外部服务的真实本地接受/认证入口与安全生命周期，不能用角色下拉框代替认证。核对入口必须能提交可核验用量并留审计，不能手改数据库。
