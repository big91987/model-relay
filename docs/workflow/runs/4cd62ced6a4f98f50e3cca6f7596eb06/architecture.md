## 2. 目标、责任与平台承诺

平台管理员准备服务与公共模型、价格、租户边界，运营接入失败、未核对用量、结账、更正、备份恢复和安全事件。租户管理员在平台边界内管理成员、应用Key、配额及预算，承担应用Key退出责任。开发者读取分配应用的安全元数据及诊断，持有经管理员安全交付的调用秘密。财务观察者核对本租户用量、价与账单，读取和导出；不写配置。模型服务提供者管理已有推理端点及真实用量事实，通过平台管理员接入，不需要虚构提供者登录角色。

价值路径：安装取得真实管理员身份 → 服务接入/核验 → 模型发布/价格 → 租户授权/预算 → 邀请真实接受 → 应用Key及诊断分配 → 普通/SSE → 同ID诊断/核对 → 结束周期结账/更正 → 变更、退出和恢复。保存、核验、成功生成、用量完整、账单结清是不同事实。

产品提供受支持的UI、管理API和Go运营命令；正常业务不依赖手改库。暂停、权限收窄、轮换不清历史；新模型默认无授权；当前身份、范围和限制由服务端判断。应用和人员身份分离，成员退出不盲目撤销应用Key。

本期边界是内部逻辑隔离、单实例、供应商/已有自托管端点管理、Chat Completions普通/SSE；不承诺GPU部署、外部售卖/支付、额外模型协议、多区域HA及生产吞吐SLO。目录可展示其他能力，但不可调用项明确标识并拒绝，不用虚假按钮宣称支持。

## 3. 能力、领域和事实源

| 能力结果 / 领域 | 拥有的事实和生命周期 | 唯一写入方 / 相邻契约 |
|---|---|---|
| 可核验服务与模型 / 模型接入 | 服务、配置版本、核验结果、公共名、候选、能力和租户授权 | Go配置服务；管理员命令；向准入提供当前有效配置，向定价提供稳定公共名 |
| 真实成员和范围 / 身份治理 | 用户、会话、租户、邀请、成员、角色、诊断分配 | Go身份服务；向全部管理查询提供服务端scope，向准入提供租户状态 |
| 安全应用访问 / Key治理 | 稳定Key ID、秘密代际、期限/状态、模型选择 | Go Key服务；每一代指向同一Key池，历史和授权不依赖秘密字符串 |
| 可兑现资源边界 / 准入计量 | 次数、窗口、并发持有、Tokens/费用预留、逻辑请求、尝试及用量证据 | Go准入/执行/核对事务；网络调用在事务外；向账本给不可重复的计量差额 |
| 可核对分账 / 价格与账单 | 价格版本、请求快照、成本与租户费追加项、周期关闭、更正 | Go计费服务；平台管理员正式核对/结账/更正；财务查询不写事实 |
| 连贯支持与恢复 / 诊断运营 | 审计、同ID尝试、分页/分析、备份、迁移结果、运行版本 | Go审计/查询/运营命令； UI只派生显示，测试证据不混入运营数据库 |

事实源是一个数据目录内的SQLite及其受管理加密材料；领域共用事务但只由所属Go业务方法写入。统计、图表、账单展示和权限菜单都是派生视图，无独立事实源或缓存授权。审计与关键业务写入同事务，不用第二队列掩盖写入丢失。

稳定标识：现有公共模型alias、upstream ID、Key ID和Request ID继续使用。成员以tenant/user复合键，尝试以request/ordinal复合键，诊断以tenant/user/key复合键；秘密代际、邀请、价格版本、核对和更正有独立生命周期才使用独立身份。应用名称为Key属性；当前一个稳定Key控制池即可承担共享代际责任，不增加应用管理微服务。

## 4. 逻辑、信任与故障边界

```text
人员浏览器 --同源会话/CSRF--> Go管理入口 --当前身份/成员scope--> 领域命令/查询
应用/调用测试 --Bearer调用Key--> Go /v1入口 --原子准入--> 请求/候选快照
                                              | 事务外 HTTP/SSE
                                              v
                                       供应商/已有推理服务
                                              |
                      尝试证据/终态 <-- 用量/超时/取消 --+
                             |
                  原子结算/保留未知预留 --> 追加双费用账本 --> 分析/账单
所有关键写入 -------------------------> 同一SQLite事务及脱敏审计
Go运营命令 ---------------------------> 数据目录锁/升级/一致备份/恢复
```

浏览器角色标签不是授权来源；租户ID、Key ID、筛选条件均为不可信输入。所有列表/详情/搜索/分页/聚合/CSV在SQL执行前加入服务端范围；开发者只能分配Key集合。租户切换是选择已有资格，不是领取资格。应用Key不能调用管理API；人员会话不作为供应商调用凭据。数据目录/加密文件属于本地运维特权边界，不宣称抵抗有主机写权限的管理员篡改。

数据面准入读取持久事实；管理页或分析读取失败可局部降级，其他请求继续。认证事实、预算、账本或配置持久写入失败必须fail closed，不允许用过期缓存绕过限制。供应商失败只影响相关服务/候选，已开始输出的请求不重放。停用服务/模型/租户立即阻止新准入及未dispatch候选；已dispatch调用允许原快照执行至完成/用户取消/超时，不声称已发生供应商费用可撤回。

## 5. 关键流程与成功含义

1. **接入控制流**：管理员保存受校验配置及revision，网络核验使用该revision；完成时比较revision，不相同记过期证据。连接核验不等于生成核验。模型发布明确候选、能力、价格和空授权；授权命令显式选租户，Key不自动新增模型。
2. **身份与首次可用流**：Go init生成一次性管理员密码，真实登录会话解析用户；创建租户并邀请负责人，经手工安全交付邀请链接及接受认证取得成员资格；然后管理员签发Key、设置诊断范围。邀请过期/撤销/并发接受、最后管理员约束由同一事务检查。
3. **请求与计量流**：受理事务同时校验权限、期限、所有限制并预留有界尝试的资源和受理价格；成功提交才进入HTTP/SSE。每个可能dispatch尝试先持久标记，再访问远端。网络成功不等于账本成功；结算失败标记服务降级并保留预留，恢复重新按唯一计量键应用。
4. **取消与调和流**：客户端取消传播Go context；持久终态单向改变、并发释放一次。所有可能dispatch未知部分保留费用/Token预留；迟到证据通过正式核对命令追加差额，不改变取消/中断终态。重启不重放生成。
5. **费用流**：尝试价格快照独立计算成本和租户费；部分已知只结已知，缺值显示null/待确认。平台管理员凭证据核对；结束周期无待确认才可关闭；更正为另一个追加事件，不改原请求或原账单。
6. **运营与支持流**：Request ID贯通拒绝原因、授权快照、尝试、终态与费用；平台管理员看异常与待确认队列，租户/开发者仅范围内事实。数据目录锁、备份、升级和失败恢复由Go命令及文档支持，缺凭据不伪造供应商成功。

全部命令路径、并发不变量和边界错误详见implementation-contract；所有异步行为都有请求/尝试/版本关联，后台只做启动恢复和确定性调和，不引入未知消息投递语义。

## 6. 部署、工作负载与演进

一个Go二进制服务嵌入HTML/CSS/JavaScript，同实例管理与代理，现有SQLite WAL/目录锁、Go模块与密码/凭据机制继续使用。默认loopback，其他监听与可信代理需单独运维配置，不扩大本节点权限。测试使用临时目录和随机端口；8793仅为编排服务，不作为产品发布入口。

事务短、无网络/哈希等待；独立网络并发受全局保护及tenant/Key C约束。一个请求最多3个有序尝试，沿用已有路由限制；受理预留覆盖全部可能尝试。请求体、响应/SSE帧、时间、列表page_size、导出行数/时间均有明确上界；超限返回错误或分批导出，不悄悄截断。

验证工作负载至少2租户、每租户多个Key、多公共模型/候选、超过一页记录以及并发竞争；它是正确性/容量探针，不是生产吞吐声明。建议记录准入/生成成功率、TTFT和总时延、429原因、待确认数量/最早时间、SQLite失败、运行版本；未知统计不当零。服务管理员工作时间内处理预留长期占用/异常，当前不承诺7×24支持或生产错误预算。

当前恢复契约：已提交的本地状态在受控进程崩溃中保持；远端dispatch结果可能未知，必须可追踪且保守预留。备份恢复只承诺快照时点的数据，实际RTO/RPO以演练测量，不造数字。重要质量场景及故障处理在verification-design和migration-and-operations落实。

可信变化及最小接缝：第二种协议出现时新增内部协议处理并独立验证；SQLite写等待/管理时延成为实测瓶颈时评估存储替换，保留tenant/key/request/账本语义及迁移校验；外部身份出现时用户认证来源可联合，成员资格与资源授权仍由本产品；公开售卖需另定义支付和对账，不把本次USD测试分账扩大成商业承诺。本轮不预建公共插件API、消息总线、GPU控制面或组织级流程。
