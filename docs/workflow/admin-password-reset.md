# 本机管理员密码重置

用户需要为现有测试安装设置指定的管理员密码。首版只有初始化生成随机密码，没有后续修改入口。新增 `reset-password --password-stdin`，作为 Go CLI 的正式运维命令；不增加管理网页或远程重置接口。

命令读取一行非空 UTF-8 密码，最多 1024 字节，不接受命令行明文密码，不回显输入。它要求原主密钥验证成功、服务停止并获得安装独占锁，以事务更新唯一管理员的 Argon2id salt/hash；现有上游、模型、应用密钥和记录保留。重启服务使旧内存会话失效。首次初始化密码文件保留其历史含义。

真实 CLI/HTTP 回归先因缺少 `--password-stdin` 失败，实现后通过：运行中拒绝、缺少显式 stdin 标志拒绝、空值／多行／超长输入拒绝、缺少主密钥拒绝；重置后旧密码与旧会话返回 401，新密码登录成功，模型和应用密钥状态保留。完整 `make verify` 已退出 0，包含 Go race／真实 HTTP 及 1280px、390px 实际 Go 服务浏览器旅程；发布使用既有 main 自动准备、Owner 手动部署。
